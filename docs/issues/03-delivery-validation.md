# 03 业务验证与员工交付包

Status: ready-for-agent
Execution: open
Blocked by: 01, 02

实现范围：按规格验证同一构建的桌面/托盘/取消/真实断开、公司内网与 GPT、飞书与外网路径；更新使用说明，生成源码包和员工包、SHA256及清晰验收结果。

单独记录本机、公司外、首次安装及飞书登录态可获得的范围；不能把网络层探测当成飞书60分钟消息业务验收。所有已授权且环境具备的验证持续完成；无法取得的员工外网复现材料标明待验证。

交付包含重现工具与部署回滚说明；未经明确授权不发员工通知。父对话负责真实本机/服务器操作，子任务只实现可在独立 worktree 完成的工具、打包及说明。
