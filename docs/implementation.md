## 打包与最终验收

[`tools/package_release.py`](../tools/package_release.py) 接受明确的 EXE、源码仓库、公开 payload 和新输出目录，生成员工 ZIP、可构建源码 ZIP、SHA256 与验证摘要。源码按 Git 跟踪清单收集，并限制目录和扩展名；载荷只允许固定的 11 项。脚本核验 EXE 版本、内嵌载荷对应关系和 ZIP 完整性，记录 Git HEAD、工作区修改标记及逐文件哈希。调用方法、部署和回滚见 [README](../README.md)。

验证摘要只记录打包实际执行的检查，业务验收默认 pending；具体已验证范围以上表和维护验收为准。全新设备与 Windows 10 安装、最终构建的完整界面实测、公司外授权文档/图片、60 分钟消息稳定性及 Google 尾部性能仍待相应环境验证。用户已暂缓同事电脑调查，保留后续现场验收入口。

发布工具不安装客户端、不改变当前桌面或网络、不上传 Release，也不覆盖旧交付目录。本轮最终 EXE 来自审阅修正后的 e178b5d，后续提交只更新文档；本机安装和交付使用相同字节。原始 1.2 包保留。

交付工具已在独立工作区验证：载荷 11 项、EXE 版本及内嵌载荷一致性、ZIP CRC/成员哈希和外部 SHA256 清单均通过；相同输入连续打包字节一致，已有输出目录被拒绝覆盖。父任务也已从最终代码的源码 ZIP 使用随包载荷重新编译成功。更新后的说明随最终源码包交付，实际成员数和 Git HEAD 以随包摘要为准。
