公司网络 1.3 使用说明

第一次使用，先解压员工包，运行其中的“公司网络.exe”，点击“连接”（新电脑可能显示“安装并连接”），按 Windows 提示安装必要组件，使用管理员分配的个人账号登录。首次连接时会创建一个桌面“公司网络”入口，以后从这里打开即可。连接成功后窗口会保留，状态显示当前连接结果。

日常操作
1. 打开 GPT：在窗口或右下角系统托盘菜单选择“打开 GPT”。原网页入口与 API 地址沿用已有配置。
2. 关闭窗口：右上角 × 立即关闭窗口，网络连接及正在进行的后台操作继续。关窗不等于断开。
3. 找回窗口：再次双击桌面“公司网络”，或在右下角托盘菜单选择“显示窗口”。图标可能在 Windows 的隐藏图标区。
4. 断开：在窗口点击“断开”，或从托盘选择断开/取消。等待明确显示已断开；出现失败或尚未确认时，保留提示并重试。
5. 退出后台：在托盘选择“断开并退出”，确认断开成功后应用退出。连接过程中也可选择取消，系统组件操作可能需要继续等待。

升级
保留原安装包。从 1.2 升级时，先在旧窗口点“断开”再关闭旧窗口；已经使用 1.3 的电脑，可在托盘选择“断开并退出”结束旧版后台。然后解压运行管理员提供的新版并连接。升级会合并本应用拥有的旧连接、断开和 GPT 快捷方式，保留一个“公司网络”入口，并复用已有组件及个人账号。提示同名快捷方式冲突时，将提示交给管理员确认。

遇到问题
窗口显示已连接，只代表公司网络连接状态；飞书文档、消息或某个网站仍须实际打开确认。公司 VPN 入口绕行代理的问题已调整，本机测试中位等待缩短；Google 偶发较慢请求仍存在。同事电脑上的飞书断连、文档 ERR_FAILED 暂待现场验证。
记录发生时间、所在网络、使用的程序和错误现象；在窗口选择“导出诊断”，检查保存内容后通过公司指定渠道交给管理员。诊断不会自动发送。请勿发送密码、登录验证码、带临时登录令牌的完整链接、文档正文或个人配置目录。

文件核对
员工包中包含“公司网络.exe”、本说明、SoftEther 引擎 LICENSE.txt 和 SHA256SUMS.txt。可请管理员协助用 PowerShell 的 Get-FileHash -Algorithm SHA256 核对文件；外层 EXE 未签名，按公司批准的来源获取。
